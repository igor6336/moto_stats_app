# SPEC: мото-телеметрия (PWA для iPhone)

## 1. Цель
Личное приложение для двух человек (владелец и друг): запись поездки на мотоцикле и статистика с индивидуальными метриками. Не коммерческий продукт, App Store не нужен.

## 2. Решения, которые уже приняты
- **Формат:** PWA (сайт, добавляемый на экран «Домой» из Safari). Без App Store, TestFlight и аккаунта разработчика.
- **Основная платформа:** iPhone (iOS 16.4+ желательно, из-за Wake Lock). Android у друга: приложение должно работать и там, но приоритет iPhone.
- **Окружение разработчика:** ноутбук на Windows, Mac нет. iPad есть (GPS в нём, скорее всего, нет, использовать только для просмотра данных).
- **Хостинг:** HTTPS обязателен (иначе GPS и датчики не работают). Кандидаты: GitHub Pages, Netlify. Проверить доступность из РФ на телефонах обоих.
- **Крепление телефона:** жёсткий статичный держатель на мотоцикле с виброгасителем. Ориентация телефона фиксирована (портрет, экран к водителю), между поездками не меняется.
- **Питание:** от мотоцикла, иначе батарея не выдержит.
- **Нативное приложение** (Swift/React Native, фоновая геолокация) отложено. Блокеры: нет Mac, аккаунт Apple Developer $99/год (оплата из РФ не проверена). Алгоритмы пишутся так, чтобы переноситься в натив без изменений (чистые функции, отдельный модуль от UI).

## 3. Главное ограничение PWA
Заблокированный или выключенный экран = страница приостановлена, GPS и датчики перестают работать. Обойти из веба нельзя.
Решение:
- Wake Lock API, чтобы экран не гас.
- «Чёрный режим»: страница заливает экран чёрным (OLED почти не потребляет), показывает минимум (скорость). Яркость пользователь снижает вручную.
- Блокировка касаний от случайных нажатий, снимается долгим нажатием.
- Риск: перегрев телефона на солнце при зарядке и включённом экране. Осенью/весной слабее.

## 4. Метрики
| Метрика | Источник | Ожидаемая точность |
|---|---|---|
| Маршрут | GPS | ±5-10 м |
| Макс. и средняя скорость | GPS-скорость (Доплер) | ±1-2 км/ч |
| Зоны скорости (время и дистанция в каждой) | GPS | ±1-2 км/ч |
| Лучшие 0-100, 100-200, 0-200 | GPS (1 Гц) + акселерометр для уточнения | ±0.3-0.6 с |
| Макс. наклон влево/вправо | скорость GPS + угловая скорость гироскопа, ≈ atan(v·ω/g), либо фильтр гироскоп+акселерометр | ±3-5° |
| Макс. угол стойки (заднее колесо) | тангаж телефона минус калибровка | ±3-6° |

Все цифры точности: это оценки по физике метода, не измерения. Реальная точность определяется на тестовых поездках.

### Известные источники ошибок
- GPS в iOS: ~1 запись в секунду. Разгон 0-100 длится ~3 с, то есть 3-4 точки.
- «Лучшее время из нескольких заездов» смещено в оптимистичную сторону (выигрывает удачный шум). Сравнивать нужно заезды, снятые одним способом, а не с паспортными цифрами.
- Наклон считается по динамике движения («мотоцикл + пилот»). Если пилот свешивается с седла, наклон рамы меньше показанного.
- Пики шумного сигнала завышены, поэтому максимумы считать по сглаженному окну (короткое скользящее).
- Стойка: подвеска приседает, виброгаситель качается при разгоне, фильтр ориентации iOS подтягивает вертикаль к ускорению. Возможна систематическая ошибка.

## 5. Калибровка
- Перед каждой поездкой: мотоцикл стоит ровно и вертикально (центральная стойка или кто-то держит), замер 3-5 секунд. Это нулевая точка наклона и тангажа.
- На боковой стойке калибровать нельзя.
- Если ориентация телефона в держателе меняется, калибровка переделывается.

## 6. Технические требования
- Датчики: Geolocation `watchPosition` (high accuracy), `DeviceMotionEvent` / `DeviceOrientationEvent` на максимальной частоте.
- iOS требует разрешение на датчики движения через `DeviceMotionEvent.requestPermission()`, вызывать только по нажатию кнопки (user gesture).
- Запись **сырых данных** (GPS и датчики с метками времени) обязательна, чтобы алгоритмы можно было пересчитывать оффлайн без новых поездок. Формат: JSON или CSV, с экспортом файла.
- Хранение: IndexedDB. Установленные на экран PWA Safari не очищает по таймеру, в обычной вкладке данные могут стереться через 7 дней неактивности. Запускать только с иконки. Экспорт/бэкап обязателен.
- Алгоритмы (наклон, стойка, разгоны, зоны) вынести в отдельный модуль на чистых функциях, чтобы их можно было тестировать на записанных файлах (в идеале прогон на Node без браузера).
- Service worker + manifest для установки и работы без сети. Карта: подложке нужен интернет, линия маршрута рисуется и без него.
- Дизайн: аккуратный, мобильный, тёмная тема, крупные элементы для использования в перчатках.

## 7. Экраны
1. **Запись:** крупная скорость, старт/стоп, калибровка, чёрный режим, блокировка касаний.
2. **Поездка:** маршрут на карте, макс. и средняя скорость, зоны скорости, макс. наклоны влево/вправо, лучшие разгоны, стойка.
3. **История:** список поездок (дата, дистанция, время, макс. скорость).
4. **Рекорды:** лучшие значения за всё время с датой и ссылкой на поездку.
5. **Сравнение с другом:** на старте через обмен файлами рекордов (экспорт/импорт). Общий бэкенд (Firebase/Supabase) только если обмен файлами надоест, и с проверкой доступности из РФ.
6. **Настройки:** границы зон скорости, единицы, экспорт/импорт.

## 8. План по этапам
1. **Прототип записи:** GPS + датчики на макс. частоте, экспорт сырых данных, на экране скорость, маршрут, макс./средняя скорость, зоны. Wake Lock и чёрный режим. Публикация на HTTPS.
2. **Тестовые поездки:** 2-3 реальных поездки, выгрузка файлов.
3. **Подгонка алгоритмов оффлайн:** наклон, стойка, разгоны. Проверки: статичный наклон мотоцикла под известным углом (уровень или inclinometer на втором телефоне), скорость сверять со вторым навигатором, повторяемость (разброс больше 0.5 с или 5° означает доработку).
4. **Встроить алгоритмы в приложение:** добавить экраны истории и рекордов, дизайн.
5. **Сравнение с другом.**
6. **По результатам решить, нужна ли нативная версия.**

## 8а. Социальные функции (добавлено)
Регистрация (логин/пароль, имя, мотоцикл, аватар, код друга), карта друзей (только пока приложение открыто), лидерборды среди друзей. Сервер: Supabase Free. Телефон и антирадар отложены.

## 9. Безопасность
Замеры 0-200 и стойки делать только на закрытой территории или треке, не на дорогах общего пользования.

## 10. Открытые вопросы
- Доступность GitHub Pages / Netlify из РФ на телефонах обоих.
- Версия iOS на основном iPhone (нужна 16.4+ для Wake Lock).
- Место крепления держателя (руль или бак) и модель телефона: влияет на калибровку и вибрации.
- Нужны ли дополнительные индивидуальные метрики сверх списка (кол-во поворотов, доля времени выше лимита, лучшее время на постоянном маршруте и т.п.).
- Оплата Apple Developer из РФ, если дойдёт до нативной версии (не проверено).
