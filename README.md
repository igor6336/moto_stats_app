# Мото телеметрия (PWA)

Личное приложение для записи поездок на мотоцикле: GPS и датчики движения с сохранением сырых данных. Спецификация: [SPEC.md](SPEC.md).

Сейчас готов **этап 1**: прототип записи.

## Что умеет
- Запись GPS (`watchPosition`, high accuracy) и датчиков (`devicemotion`, `deviceorientation`) с метками времени.
- Сброс сырых данных в IndexedDB каждые 5 с и при сворачивании. При падении теряется максимум 5 с, прерванная поездка восстанавливается при следующем запуске.
- Экран записи: крупная скорость, дистанция, время в движении, макс./средняя, состояние GPS/датчиков/Wake Lock.
- Калибровка (4 с, мотоцикл ровно и вертикально): пока только сохраняет вектор гравитации. Углы наклона и стойки считаются на этапе 3.
- Чёрный режим и блокировка касаний; выход и «Стоп» по удержанию.
- Экран поездки: карта (OSM; без сети рисуется только линия), статистика, зоны скорости, качество данных.
- Экспорт сырых данных поездки (JSON), резервная копия всех поездок (без данных датчиков), импорт обоих форматов.

## Установка на iPhone
1. Открыть адрес приложения в Safari.
2. «Поделиться» → «На экран «Домой»».
3. Запускать **только с иконки**: в обычной вкладке Safari может удалить данные через 7 дней.
4. На экране записи нажать «Включить датчики» и разрешить геолокацию и «Движение и ориентация».

Сохранение файла: «Экспорт сырых данных» → «Сохранить файл» → «Сохранить в Файлы». Кнопку нужно нажать дважды, потому что iOS не даёт открыть меню «Поделиться» после долгой подготовки файла.

## Разработка
Без сборки и зависимостей, чистые ES-модули.

```
npm test                          # тесты алгоритмов (Node 18+)
npm run serve                     # локальный сервер на :8080
node scripts/analyze.mjs file.json   # разбор экспортированной поездки без браузера
```

Структура:
- `src/algo/`: чистые функции без браузерных API (статистика, калибровка, качество данных, формат). Тестируются на Node и переносятся в нативную версию.
- `src/recorder.js`: датчики и запись. `src/storage.js`: IndexedDB. `src/export.js`: экспорт и импорт.
- `src/screens/`: экраны.
- `sw.js`: офлайн-кэш.

**При каждом деплое** увеличивайте `VERSION` в `sw.js` и `APP_VERSION` в `src/version.js`, иначе телефоны продолжат работать со старой закэшированной версией. После обновления приложение покажет полосу «Доступна новая версия».

## Формат сырого файла
`format: "moto-raw"`, `version: 1`. Поля `columns` и `units` описывают массивы `gps`, `motion`, `orient`, `events`. Время `t` указано в мс от начала поездки. В `ride` лежат метаданные: устройство, калибровки, настройки зон.

Известно: единицы `rotationRate` на старых Android могли отличаться (рад/с вместо град/с). `ride.device.ua` сохраняется, чтобы это можно было учесть офлайн.
